# 20260322-01 美国年线回撤说明

## 1. 任务说明

本次任务针对美股三大指数：

- 标普500
- 纳斯达克100
- 道琼斯工业平均

基于历史日频收盘价，统计“跌破年线后”的后续最大回撤，并输出 Excel 结果。

## 2. 输入数据

输入目录：

`data/20260322-美国年线回撤`

当前使用文件：

`全球价格指数（更新到2026年3月21日）-for 美股-1990年开始.xlsx`

读取方式：

- 使用 `同花顺数据` sheet
- 第 3 行为指数代码
- 第 4 行为指数中文名
- 第 5 行起为正式日频数据

## 3. 年线定义

本任务中的“年线”定义为：

`250 个交易日收盘价简单移动平均线（MA250）`

公式：

```text
年线(t) = 最近250个交易日收盘价的平均值
```

说明：

- 这里使用的是交易日，而不是自然日
- 之所以采用 250 日，是因为日频市场分析里通常以 250 个交易日近似一年

## 4. 跌破年线的判定方式

“跌破年线”定义为：

- 前一交易日收盘价 >= 前一交易日年线
- 当日收盘价 < 当日年线

也就是从“年线上方或等于年线”首次切换到“年线下方”的那一天，记为一次跌破事件。

## 5. 后续最大回撤的计算区间

每次跌破年线后，观察区间定义为：

- 起点：跌破年线当日
- 终点：重新站上年线前一日

如果样本结束前一直没有重新站上年线，则：

- 终点：样本最后一个交易日

“重新站上年线”定义为：

- 收盘价 >= 年线

## 6. 最大回撤计算方式

在每次跌破事件对应的观察区间内，按累计峰值法计算最大回撤：

```text
回撤 = (当前价格 - 区间内历史最高价格) / 区间内历史最高价格
最大回撤 = 回撤序列中的最小值
```

同时记录以下时间：

- 跌破年线日期
- 重新站上年线日期
- 观察区间结束日期
- 后续最大回撤开始日期
- 后续最大回撤结束日期

## 7. 输出文件

输出目录：

`output/20260322-美国年线回撤`

当前生成文件：

`全球价格指数（更新到2026年3月21日）-for 美股-1990年开始_跌破年线后最大回撤分析_20260322.xlsx`

工作簿结构：

- `汇总统计`
- `标普500`
- `纳斯达克100`
- `道琼斯工业平均`

其中：

- `汇总统计`：汇总每个指数的跌破次数、最差后续最大回撤、平均后续最大回撤等
- 三个指数 sheet：逐次列出每一次跌破年线事件的详细时间和回撤结果

## 8. Excel 输出参数说明

### 8.1 汇总统计 sheet

`汇总统计` sheet 按指数汇总历史上所有跌破年线事件，字段含义如下：

- `指数名称`：指数中文名称，例如标普500、纳斯达克100、道琼斯工业平均
- `指数代码`：原始数据中的指数代码，例如 `SPX.GI`、`NDX.GI`、`DJI.GI`
- `跌破年线次数`：样本期内识别出的跌破年线事件总次数
- `首次跌破年线日期`：该指数历史上第一次被识别为跌破年线的日期
- `最近一次跌破年线日期`：该指数历史上最近一次被识别为跌破年线的日期
- `最差后续最大回撤`：所有跌破事件中，后续最大回撤最深的一次
- `平均后续最大回撤`：所有跌破事件对应后续最大回撤的平均值
- `中位数后续最大回撤`：所有跌破事件对应后续最大回撤的中位数
- `平均观察交易日数量`：从跌破年线到重新站上年线前一日的平均交易日长度
- `未重新站上年线次数`：在样本结束前仍未重新站上年线的事件次数

说明：

- `最差后续最大回撤`、`平均后续最大回撤`、`中位数后续最大回撤` 均以百分比展示
- 这些回撤数值为负数，绝对值越大，说明跌破年线后下跌越深

### 8.2 指数明细 sheet

`标普500`、`纳斯达克100`、`道琼斯工业平均` 这三个 sheet 的字段完全一致，每一行对应一次跌破年线事件，字段含义如下：

- `指数名称`：指数中文名称
- `指数代码`：指数代码
- `事件序号`：按时间先后排序的跌破事件编号，从 1 开始
- `跌破年线日期`：首次从年线上方或等于年线转为低于年线的交易日
- `跌破年线收盘价`：跌破年线当日的收盘价
- `跌破当日年线`：跌破当日对应的 MA250 数值
- `是否重新站上年线`：该次事件在后续样本中是否重新回到年线上方或等于年线
- `重新站上年线日期`：重新站上年线的日期；若样本结束前未站回，则为空
- `观察区间结束日期`：本次回撤观察区间的结束日期
- `区间交易日数量`：从跌破年线日期到观察区间结束日期之间的交易日数量
- `区间收益率`：观察区间结束时相对跌破当日的累计收益率
- `跌破后最低点日期`：本次观察区间内最低收盘价对应的日期
- `跌破后最低点价格`：本次观察区间内的最低收盘价
- `跌破日至最低点跌幅`：从跌破年线当日价格到区间最低点价格的跌幅
- `后续最大回撤`：在本次观察区间内，按累计峰值法计算得到的最大回撤
- `后续最大回撤开始日期`：本次后续最大回撤对应的起点日期，即回撤前局部高点日期
- `后续最大回撤结束日期`：本次后续最大回撤对应的终点日期，即回撤最低点日期
- `后续最大回撤持续天数`：后续最大回撤开始日期到结束日期之间的自然日天数
- `年化收益率`：观察区间内按区间首尾价格折算得到的年化收益率
- `年化波动率`：观察区间内日收益率折算得到的年化波动率
- `夏普比率`：年化收益率除以年化波动率

说明：

- `区间收益率`、`跌破日至最低点跌幅`、`后续最大回撤`、`年化收益率`、`年化波动率` 均以百分比展示
- `后续最大回撤`和`跌破日至最低点跌幅`通常为负数
- `后续最大回撤`不一定等于`跌破日至最低点跌幅`

原因是：

- `跌破日至最低点跌幅`以“跌破当日价格”为起点
- `后续最大回撤`以“观察区间内某一历史峰值”为起点

如果跌破年线后先有反弹、再继续下跌，那么后续最大回撤可能发生在跌破之后的某个局部高点到低点之间。

## 9. 脚本位置

脚本文件：

`src/20260322-美国年线回撤/analyze_break_below_yearline.py`

脚本主要功能：

- 读取原始 Excel
- 计算 MA250 年线
- 识别每次跌破年线事件
- 计算跌破后的后续最大回撤及对应时间
- 输出到指定目录的 Excel 文件
