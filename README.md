# 指数分析工具集

## 项目简介

本项目包含两个核心工具：

1. **最大回撤计算工具** (`calculate_drawdown.py`)：计算任意指数的每年度最大回撤，并输出为Excel文件。支持多个指数同时分析，自动按年度统计最大回撤及相关指标。
2. **回测分析工具** (`backtesting_analysis.py`)：计算指定年份到现在的年化收益率、波动率和夏普比率，用于评估指数的长期表现。

## 功能特点

### 最大回撤计算工具

- 支持多个指数同时分析
- 自动按年度计算最大回撤
- 详细记录回撤的开始时间、结束时间和持续时间
- 可扩展的频率设置（支持日度、周度、月度等）
- 结果以Excel多Sheet形式输出，便于查看和分析
- 自动数据清洗：剔除值为0的数据点（表示指数数据尚未出现）
- 智能处理：自动跳过数据不足的年份

### 回测分析工具

- 计算长期年化收益率（从指定年份到当前）
- 计算年化波动率（基于日收益率，年化到252个交易日）
- 计算夏普比率（定义为收益率/波动率）
- 支持自定义起始年份（默认从当前年份往前推10年）
- 支持多个指数批量分析
- 自动数据清洗：剔除值为0和缺失值的数据点
- 结果以Excel单表形式输出，便于对比分析

## 数据要求

### 输入数据格式

输入数据存放在 `data` 文件夹中，为Excel表格文件：

- **第一列**：日期（支持常见日期格式）
- **第二列及其他列**：各个指数的收盘价
- **数据频率**：默认为日度数据（可在代码中调整频率参数）
- **数据值说明**：如果某个时点的指数值为0，表示该指数在该时点尚未出现，程序会自动剔除这些数据点

示例数据格式：

| 日期       | 上证指数 | 深证成指 | 沪深300 |
| ---------- | -------- | -------- | ------- |
| 2023-01-01 | 3200.5   | 11500.2  | 4100.3  |
| 2023-01-02 | 3210.8   | 11520.5  | 4110.6  |
| 2023-01-03 | 0        | 11530.8  | 4115.2  |
| ...        | ...      | ...      | ...     |

**注意**：上例中2023-01-03的上证指数为0，程序会自动剔除该数据点，不影响其他指数的计算。

### 输出数据格式

#### 最大回撤分析输出

输出为Excel文件，包含以下特点：

- **文件命名**：`{输入文件名}_指数回撤分析结果_YYYYMMDD.xlsx`
  - 例如：`快照 全球价格指数（更新到12月18日）_指数回撤分析结果_20251201.xlsx`
- **Sheet命名**：`{指数名称}_回撤分析`
  - 如果指数名称过长（超过31个字符），会自动截断
- **每个Sheet包含的列**：
  - **第一列**：年份
  - **第二列**：最大回撤（百分比，负数表示回撤）
  - **第三列**：回撤开始时间（该年度内回撤开始前的最高点日期）
  - **第四列**：回撤结束时间（该年度内回撤的最低点日期）
  - **第五列**：最大回撤持续时间（天数，从开始到结束的天数差）

#### 回测分析输出

输出为Excel文件，包含以下特点：

- **文件命名**：`{起始年份}年开始的回测统计_YYYYMMDD.xlsx`
  - 例如：`2015年开始的回测统计_20251222.xlsx`
- **Sheet命名**：`回测统计`
- **表格包含的列**：
  - **第一列**：指数名称
  - **第二列**：年化收益率（百分比）
  - **第三列**：年化波动率（百分比）
  - **第四列**：夏普比率（收益率/波动率）

## 使用方法

### 环境要求

建议使用conda环境管理，推荐使用名为 `common`的Python环境。

所需Python包：

- pandas
- numpy
- openpyxl（用于读写Excel）

### 运行步骤

#### 最大回撤计算

1. 将待分析的指数数据Excel文件放入 `data` 文件夹
2. 运行主程序：
   ```bash
   python calculate_drawdown.py
   ```
3. 查看生成的结果文件，默认保存在 `output` 文件夹中

#### 回测分析

1. 将待分析的指数数据Excel文件放入 `data` 文件夹
2. 运行回测分析程序：
   ```bash
   python backtesting_analysis.py
   ```
3. 查看生成的结果文件，默认保存在 `output` 文件夹中

### 参数配置

#### 最大回撤计算工具

可以在 `calculate_drawdown.py` 中调整以下参数：

- `freq`: 数据频率，可选 'D'（日）、'W'（周）、'M'（月）等
- `input_file`: 输入文件路径
- `output_dir`: 输出文件夹路径

#### 回测分析工具

可以在 `backtesting_analysis.py` 中调整以下参数：

- `input_file`: 输入文件路径（默认：`data/快照 全球价格指数（更新到12月18日）.xlsx`）
- `output_dir`: 输出文件夹路径（默认：`output`）
- `start_year`: 起始年份（默认：当前年份-10年，即从2015年开始）

## 数据处理流程

### 数据清洗

两个工具都会对每个指数进行以下数据清洗：

1. **剔除0值数据**：自动剔除值为0的数据点（表示该时点指数数据尚未出现）
2. **剔除缺失值**：自动剔除NaN值
3. **数据验证**：如果清洗后剩余数据点少于2个，则跳过该指数的计算

### 最大回撤计算方法

最大回撤（Maximum Drawdown, MDD）的计算方法：

1. **数据预处理**：剔除0值数据点，确保只使用有效数据
2. **按年度分组**：将数据按年份分组，分别计算每年的最大回撤
3. **计算累积最大值**：对每个时间点，计算从年初到当前的历史最高价
4. **计算回撤序列**：对于每个时间点，计算从历史最高点到当前的跌幅
5. **确定最大回撤**：取所有跌幅中的最小值（最大回撤）作为该年度的最大回撤
6. **记录时间信息**：记录最大回撤发生的起始时间（最高点）和结束时间（最低点）

公式：

```
回撤 = (当前价格 - 历史最高价格) / 历史最高价格
最大回撤 = min(回撤序列)
```

**计算特点**：

- 每个指数的数据清洗独立进行，互不影响
- 按年度分别计算，确保跨年度的回撤不会影响年度统计
- 自动处理数据不足的情况，确保计算结果的准确性

### 回测分析计算方法

回测分析指标的计算方法用于评估指数从指定起始年份到当前时间的长期表现。

#### 计算步骤

1. **数据预处理**：

   - 剔除值为0的数据点（表示指数数据尚未出现）
   - 剔除缺失值（NaN）
   - 筛选指定起始年份之后的数据
   - 按日期排序，确保时间序列正确
2. **计算日收益率**：

   ```
   日收益率(t) = (价格(t) - 价格(t-1)) / 价格(t-1)
   ```

   其中 t 表示第 t 个交易日
3. **计算总收益率**：

   ```
   总收益率 = (最终价格 / 起始价格) - 1
   ```

   从起始日期到结束日期的总收益率
4. **计算实际年数**：

   ```
   年数 = (结束日期 - 起始日期)的天数 / 365 #暂时先不考虑闰年
   ```

   （若考虑闰年，则使用365.25天来考虑闰年的影响，将365替换成365.25）
5. **计算年化收益率**：

   ```
   年化收益率 = (1 + 总收益率)^(1/年数) - 1
   ```

   将总收益率年化，反映每年的平均收益率水平
6. **计算年化波动率**：

   ```
   日收益率标准差 = √(Σ(日收益率 - 平均日收益率)² / (n-1))
   年化波动率 = 日收益率标准差 × √252
   ```

   其中：

   - n 为交易日数量
   - 252 为一年中的交易日数（假设）
   - 波动率反映了收益率的离散程度，是风险的重要指标
7. **计算夏普比率**：

   ```
   夏普比率 = 年化收益率 / 年化波动率
   ```

   衡量单位风险下的超额收益，数值越大表示风险调整后的收益越好

#### 计算公式详解

**年化收益率公式推导**：

假设投资期为 T 年，总收益率为 R_total，年化收益率为 R_annual，则：

```
(1 + R_annual)^T = 1 + R_total
```

因此：

```
R_annual = (1 + R_total)^(1/T) - 1
```

**年化波动率公式推导**：

假设日收益率的标准差为 σ_daily，年化波动率为 σ_annual，交易日数为 N（通常为252），则：

```
σ_annual = σ_daily × √N
```

这是因为方差具有时间可加性，而标准差需要开平方根。

**夏普比率说明**：

- **定义**：夏普比率 = 收益率 / 波动率（本工具中的简化版本）
- **含义**：衡量每承担一单位风险所获得的收益
- **解读**：
  - 夏普比率 > 1：风险调整后表现良好
  - 夏普比率 > 0.5：风险调整后表现尚可
  - 夏普比率 < 0：收益为负或风险过大
- **注意**：标准夏普比率通常使用（收益率 - 无风险利率）/ 波动率，本工具使用简化版本

#### 计算特点

- **时间精度**：使用实际天数计算年数（考虑闰年），而非固定365天
- **交易日假设**：波动率年化时假设一年有252个交易日（约52周 × 5个交易日 - 节假日）
- **独立性**：每个指数的计算独立进行，互不影响
- **数据质量**：自动剔除无效数据，确保计算结果的准确性

## 注意事项

1. **日期格式**：确保输入数据的日期列格式正确，程序会自动转换为datetime类型
2. **数据完整性**：数据不需要完全连续，程序会自动排序处理
3. **0值处理**：值为0的数据点会被自动剔除，这通常表示该指数在该时点尚未出现
4. **数据不足**：如果某年清洗后剩余数据点少于2个，该年会被跳过，不会出现在结果中
5. **持续时间**：输出结果中的持续时间单位与输入数据频率相关（日度数据单位为天）
6. **Sheet名称限制**：Excel的Sheet名称最多31个字符，如果指数名称过长会自动截断
7. **输出文件**：每次运行会生成新的输出文件，文件名包含时间戳，不会覆盖之前的文件
