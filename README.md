# 指数最大回撤计算工具

## 项目简介

本项目用于计算任意指数的每年度最大回撤，并输出为Excel文件。支持多个指数同时分析，自动按年度统计最大回撤及相关指标。

## 功能特点

- 支持多个指数同时分析
- 自动按年度计算最大回撤
- 详细记录回撤的开始时间、结束时间和持续时间
- 可扩展的频率设置（支持日度、周度、月度等）
- 结果以Excel多Sheet形式输出，便于查看和分析

## 数据要求

### 输入数据格式

输入数据存放在 `data` 文件夹中，为Excel表格文件：

- **第一列**：日期（支持常见日期格式）
- **第二列及其他列**：各个指数的收盘价
- **数据频率**：默认为日度数据（可在代码中调整频率参数）

示例数据格式：

| 日期 | 上证指数 | 深证成指 | 沪深300 |
|------|---------|---------|---------|
| 2023-01-01 | 3200.5 | 11500.2 | 4100.3 |
| 2023-01-02 | 3210.8 | 11520.5 | 4110.6 |
| ... | ... | ... | ... |

### 输出数据格式

输出为Excel文件，包含以下特点：

- **文件命名**：`指数回撤分析结果_YYYYMMDD.xlsx`
- **Sheet命名**：`{指数名称}_回撤分析`
- **每个Sheet包含的列**：
  - **第一列**：年份
  - **第二列**：最大回撤（百分比）
  - **第三列**：回撤开始时间
  - **第四列**：回撤结束时间
  - **第五列**：最大回撤持续时间（天数）

## 使用方法

### 环境要求

建议使用conda环境管理，推荐使用名为`common`的Python环境。

所需Python包：
- pandas
- numpy
- openpyxl（用于读写Excel）

### 运行步骤

1. 将待分析的指数数据Excel文件放入 `data` 文件夹
2. 运行主程序：
   ```bash
   python calculate_drawdown.py
   ```
3. 查看生成的结果文件，默认保存在 `output` 文件夹中

### 参数配置

可以在 `calculate_drawdown.py` 中调整以下参数：

- `freq`: 数据频率，可选 'D'（日）、'W'（周）、'M'（月）等
- `input_file`: 输入文件路径
- `output_dir`: 输出文件夹路径

## 最大回撤计算方法

最大回撤（Maximum Drawdown, MDD）的计算方法：

1. 计算累积净值序列
2. 对于每个时间点，计算从历史最高点到当前的跌幅
3. 取所有跌幅中的最大值作为最大回撤
4. 记录最大回撤发生的起始和结束时间

公式：
```
回撤 = (当前净值 - 历史最高净值) / 历史最高净值
最大回撤 = min(回撤序列)
```

## 注意事项

1. 确保输入数据的日期列格式正确且连续
2. 数据中的缺失值会自动处理
3. 如果某年数据不足，可能无法计算完整的最大回撤
4. 输出结果中的持续时间单位与输入数据频率相关
